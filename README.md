# Hot Flash Landing Page

Static GitHub Pages-compatible landing page for Hot Flash.

## Files

- `index.html` - main landing page
- `styles.css` - page styling
- `app.js` - static form success behavior
- `assets/hero.png` - hero background image
- `assets/hot-flash-logo.png` - Hot Flash logo
- `.nojekyll` - tells GitHub Pages to serve files as-is

## Deploy To GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In GitHub, go to Settings > Pages.
4. Set source to `Deploy from a branch`.
5. Choose `main` and `/root`.
6. Save.

The page uses only static files and relative paths, so it is compatible with GitHub Pages.
