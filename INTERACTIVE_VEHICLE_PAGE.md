# Interactive Vehicle Page

The public vehicle page now supports:

- Real vehicle lookup using `vehicle.html?hf=HF-000001` or `vehicle.html?id=<uuid>`
- Mobile swipe-style thumbnail gallery
- Previous/next image controls
- Owner-only multi-photo uploads
- Specs, story, and contributor tabs
- Garage cards that open the live vehicle page

## One-time Supabase setup

Run `supabase-vehicle-gallery.sql` in the Supabase SQL Editor before uploading gallery images.
