# Hot Flash PayPal Subscriptions — Deployment Checklist

The PayPal plans are already live and their plan IDs are stored in `public.membership_plans`.

## 1. Run the webhook migration

In Supabase SQL Editor, run:

```sql
-- contents of supabase-paypal-webhooks.sql
create table if not exists public.paypal_webhook_events (
  event_id text primary key,
  event_type text not null,
  provider_subscription_id text,
  payload jsonb not null default '{}'::jsonb,
  processed_at timestamptz not null default now()
);
create index if not exists paypal_webhook_subscription_idx
  on public.paypal_webhook_events(provider_subscription_id, processed_at desc);
alter table public.paypal_webhook_events enable row level security;
```

## 2. Add Supabase Edge Function secrets

Add these in Supabase Edge Function Secrets:

- `PAYPAL_CLIENT_ID`
- `PAYPAL_CLIENT_SECRET`
- `PAYPAL_API_BASE=https://api-m.paypal.com`
- `HOTFLASH_SITE_URL=https://hotflash.app`

After the webhook is created in PayPal, also add:

- `PAYPAL_WEBHOOK_ID`

Never place the PayPal secret or Supabase service-role key in browser JavaScript or commit them to GitHub.

## 3. Deploy the functions

Deploy:

- `create-paypal-subscription` with JWT verification enabled.
- `paypal-subscription-webhook` with JWT verification disabled, because PayPal does not send a Supabase user token. The function verifies PayPal's signature itself.

CLI commands:

```bash
supabase functions deploy create-paypal-subscription
supabase functions deploy paypal-subscription-webhook --no-verify-jwt
```

The repository's `supabase/config.toml` also records these settings.

## 4. Create the PayPal webhook

Webhook URL:

```text
https://juwkzmlchffbovlrqhex.supabase.co/functions/v1/paypal-subscription-webhook
```

Subscribe to:

- `BILLING.SUBSCRIPTION.CREATED`
- `BILLING.SUBSCRIPTION.ACTIVATED`
- `BILLING.SUBSCRIPTION.UPDATED`
- `BILLING.SUBSCRIPTION.CANCELLED`
- `BILLING.SUBSCRIPTION.SUSPENDED`
- `BILLING.SUBSCRIPTION.EXPIRED`
- `BILLING.SUBSCRIPTION.PAYMENT.FAILED`
- `PAYMENT.SALE.COMPLETED`
- `PAYMENT.SALE.REFUNDED`
- `PAYMENT.SALE.REVERSED`

Copy the webhook ID generated by PayPal into the `PAYPAL_WEBHOOK_ID` Supabase secret.

## 5. Test

1. Sign into Hot Flash with a test member account.
2. Open `https://hotflash.app/pricing.html`.
3. Click Start Verified or Start Plus.
4. Approve the subscription in PayPal.
5. Confirm the browser returns to `membership-success.html`.
6. In Supabase, verify a row exists in `subscriptions` and changes to `active`.
7. Verify the profile's legacy membership fields update from the database trigger.
8. Verify a `PAYMENT.SALE.COMPLETED` event creates a row in `subscription_payments`.

Do not perform the first production test with the site owner's main PayPal buyer identity if PayPal prevents the merchant from paying itself. Use a separate buyer account.
